# Repository Rules

- Read `SPEC.md` before changing behavior.
- Keep implementation under `src/ire_assn1` and configuration under `config`.
- Keep datasets and derived heavy artifacts under `data`.
- Do not modify `instructions`.
- Do not create or modify the final report or AI-attribution material.
- Do not add source comments, docstrings, emojis, notebooks, or ad hoc orchestration scripts.
- Preserve temporal boundaries, serving-time availability, deterministic ties, and typed schemas.
- Run Ruff, Pyright, and relevant Pytest tests before committing.
- Update `SPEC.md` in the same change when a public contract changes.
